# 夜冠：十二室 · Night Crown: Twelve Rooms

> 两道视野，一座会移动的城堡。
> 纯前端、零依赖、完全本地运行的双人同屏暗黑策略探索游戏。

**夜冠：十二室**是一款回合制同屏策略游戏：两名冒险者各自只能看见自己当前所在的房间，
道路每回合改变，夺取、反制与地牢会让任何一次相遇成为转折。整局穿越五个阶段，
在城堡之巅、重返的旧路与钟楼碎影之间争夺那顶血染的王冠。

游戏没有任何后端、没有账号、不联网，双击 `index.html` 就能开始。

## 快速开始

### 方式一：直接打开（最简单）

```bash
git clone <本仓库地址>
cd <仓库目录>
```

Windows 双击 **`打开本地游戏.cmd`**，或用 Chrome / Edge 直接打开 **`index.html`**。

> ⚠️ 压缩包形式获取的请**先完整解压**再打开，保留目录结构。
> 直接双击 HTML 时，文件音乐通过同目录的 `audio/bgm/*.ogg.js`（Base64 离线副本）加载，
> 以绕过浏览器对 `file://` 协议 `fetch` 的限制，所以**不需要**关闭浏览器的安全设置。

### 方式二：本地静态服务器（更接近部署环境）

```bash
# 任选其一，端口随意
python -m http.server 8080
npx serve .
```

然后访问 `http://localhost:8080/`。

**环境要求**：现代浏览器（Chrome / Edge / Firefox / Safari 均可）。
不需要 Node.js、不需要 Python、不需要构建步骤、不需要安装任何依赖。

> 浏览器要求进入游戏时**有一次点击**才会允许播放声音 —— 开始游戏的那一下点击会同时解锁声音。
> 如果声音没起来，顶栏「设置」里有「重新载入声音素材」按钮可以重试；静音状态下游戏完全可玩。

## 玩法概要

### 五个阶段

整局依次经历：

```
初次探索  →  城堡之巅  →  重返探索  →  终局之战 / 钟楼碎影（二选一）
```

初次探索的赛程可选 **6 / 8 / 12 回合**，但这只是第一段的长度，整局还要往后走。

### 核心机制

| 机制 | 说明 |
| --- | --- |
| **独立视野** | 每位玩家只能看到自己的当前房间与探索记录，双方各自锁定后统一结算 |
| **行动点** | 探索类阶段每回合 3 步、终局阶段每回合 2 步；逐级结算，每走一步城堡按新状态重新给选项 |
| **夺取** | 同房出手会显示预计夺取率；双方同时夺取且势均力敌时各失体力，差距大则劣势者入狱 |
| **地牢** | 入狱锁链限制接下来两次行动；解禁后可从普通出口离开，也可留下寻找稀有传奇装备 |
| **NPC 与好感** | NPC 并非每回合出现（基础 40%，好感每级 +10%，4 级封顶）；对话结果受属性、装备与关系影响 |
| **装备体系** | 七套六件体系（夜猎 / 蚀冠 / 破城 / 星迹 / 晨誓 / 逆命 / 夜市商会），2 / 4 / 6 件逐级成型 |
| **装备实例化** | 品质（蓝 / 紫 / 金）、成长档（1–5）、词条结果都记在具体的每一件上 |
| **阶段成长** | 每个阶段结束一次三选一，其中至少一项匹配你当前的主方向 |
| **十条角色** | 各有独立天赋与初始道具；本地双人可同屏，也可玩家对人机（2–5 个） |
| **自动存档** | 在完成的安全节点自动保存并保留上一份有效存档，支持导出 / 导入 JSON |

### 界面里的几个数字

- 顶栏属性显示的是**装备后常驻值**，旁边带三角形的表示当前还有临时状态加成；
- 箭头后的数字是这一回合的净变化；
- 常驻值 =(基础值 + 永久成长 + 装备固定值)×(1 + 同类百分比之和)，生命 / 体力 / 理智不随百分比放大。


## 技术说明

- **纯前端、零依赖**：所有脚本以经典 `<script src>` 方式加载，共享同一全局作用域。
  > ⚠️ 因此**顶层 `const` / `let` 不可跨文件重名** —— 这会直接抛出 `SyntaxError` 让整局游戏起不来。
  > 全局唯一的按键表就放在 `keys.js`，其余文件只读取别名。
- **随机源可复现**：`mulberry32` + FNV-1a 种子。给定同一个种子与同一串操作，
  随机序列完全可复现，存档里保存 RNG 的完整状态。
- **存档**：`localStorage`，带 FNV-1a 校验和；坏存档会被拒绝而不是默默加载。
  自动保存在安全节点，保留一份备用存档。
- **音频**：WebAudio 总线式音量控制；初次探索阶段为程序化实时合成，
  其余阶段使用文件音乐并由统一调度器做响度归一与交叉淡化。
- **测试桥**：`window.__nightCrownTest` 暴露核心函数，供浏览器探针与自动化验证使用。

## 已知限制

- **同屏双人**：设计为同一块屏幕共享键盘，移动端触屏体验未经适配。
- **存档按浏览器与路径隔离**：清理浏览器数据、换浏览器或移动游戏目录都可能导致
  找不到原存档 —— 迁移前请先导出 JSON。
- **AI 生成美术**：部分场景与立绘为 AI 生成后处理，风格一致性存在波动。
- **中文为主**：界面文案目前仅有简体中文。
